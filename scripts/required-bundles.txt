# Package bundles the game can actually reach, one per line.
#
# The engine ships 61; these 16 are the ones any problem in the set resolves to.
# The rest are ~130MB that nothing can load, so they are neither deployed nor
# uploaded. Read by fetch-tex-assets.sh and upload-tex-assets.sh.
#
# Do not hand-maintain this against guesswork. `npm run verify:problems` records
# every bundle the content actually fetches and fails if one is missing from this
# list, which is the only reason `\$` in text was caught: locally all 61 bundles
# are present, so a document needing a deferred one still compiles, while the
# deploy ships only what is listed here and 404s. The same run reports anything
# listed but never fetched, so this file can be trimmed safely.

core
fmt-pdflatex
l3
dvips
extra-maps

# fonts. The lm set is not optional: the shared preamble uses Latin Modern with
# T1 encoding specifically so a text dollar sign does not reach for cm-super,
# which is 56.7MB and fetched on demand.
fonts-cm
fonts-cmextra
fonts-lm-tfm
fonts-lm-type1
fonts-misc
fonts-symbols

# packages loaded by the shared preamble
amsmath
graphics
tex-latex-misc
